# tensiones.md — tensiones de la tesis y del paper

Este directorio registra las tensiones, controversias y problemas abiertos del paper. Es el lugar donde
el red team, el writer y el editor documentan lo que el paper necesita decidir, lo que el paper afirma y
que es discutible, y lo que los agentes del equipo consideran objeciones reales.

## Archivos

- `t1-amor-categoria-operativa.md` — la tensión T1: si el amor operativo es "solo conducta" o es una
  categoria operativa. Este archivo registra la tension, la respuesta del paper al borrador actual, el
  veredicto del red team, y las objeciones O1, O2, O3 que el paper debe responder.
